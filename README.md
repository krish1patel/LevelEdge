# LevelEdge forecast ledger

Append-only, hash-chained forecasts in ledger.jsonl, committed before their outcomes and timestamped by freetsa.org.

Verify: `python ledger.py verify https://raw.githubusercontent.com/krish1patel/LevelEdge/ledger/ledger.jsonl` with [ledger.py](https://github.com/krish1patel/LevelEdge/blob/main/src/leveledge/ledger.py).
